# Data

The data files are not included in the repository because of their size (~2.2 GB).

Download the [Game Recommendations on Steam](https://www.kaggle.com/datasets/antonkozyriev/game-recommendations-on-steam) dataset from Kaggle and copy these files into this folder:

- `games.csv`
- `users.csv`
- `recommendations.csv`
- `games_metadata.json`

The first run creates `filtered_reviews.pkl` here, a filtered cache that makes later runs much faster.
